# MVSA demographic-stage dependencies.

# DO NOT `pip install -r requirements-demographics.txt` blindly on the
# research server. The existing environment already has a working, pinned
# stack that MUST NOT change:
#
#   torch        2.1.0+cu118
#   torchvision  0.16.0+cu118
#   numpy        1.26.1
#
# None of those three packages are listed below, on purpose. If any command
# in this file, or any package it pulls in, tries to upgrade one of them,
# stop and investigate rather than letting pip proceed -- see
# README.md "Installing demographic dependencies safely" for the exact,
# step-by-step, --no-deps-based install procedure and a verification command
# to run afterward.
#
# ultralytics (already installed on the server) already provides opencv and
# PyYAML in a version known to work with the pinned torch/torchvision, so
# those are intentionally not pinned again here.
